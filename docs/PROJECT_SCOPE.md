# Scope and evidence

Completed implementation: three chart views, CSV upload and validation, campaign filtering, HTML tables, summary refresh, optional AI summary API, strict summary validation, automated test suites, and CI configuration.

The UI uses upstream AutoVizuA11y features; this is not a new accessibility library. Numeric claims are limited to exact totals and leading-campaign comparisons. No LLM accuracy percentage is claimed without an actual evaluated provider run.

Potential future work: CSV column mapping, larger datasets with aggregation controls, natural-language questions backed by constrained query execution, full assistive-technology testing, and a documented user study.

Resume wording must describe implemented work and measured checks. A fork, dependency integration, or synthetic validator benchmark does not establish production adoption or disability user outcomes.
